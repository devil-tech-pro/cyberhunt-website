# CyberHunt — Plain HTML

This version uses normal HTML pages, one shared CSS file, and small inline JavaScript blocks. No React, Vite, npm, or build step is required.

Open `index.html` directly in a browser.

## Edit
- Page structure/content: edit each `.html` file directly.
- Design/colors/responsive layout: `css/styles.css`.
- Images: `assets/`.

## Production security
The static demo never stores passwords. The login marker in localStorage is only a front-end demo state. For real hosting, authentication, sessions, OAuth, password reset, authorization, rate limiting, CSRF protection, server-side validation, secure cookies, HTTPS/HSTS, CSP, and database access must be implemented server-side.
